The problem

Finding a flatmate is the easy part. Trusting them is not.

News reports from Bengaluru, Mumbai and Gurugram describe the same pattern: deposits that never come back, bills nobody pays, and people who turn out not to be who they said.

Deposit disputes

Deductions for repainting, deposits kept after move-out, and no written record of what was agreed.

Shared bills that drift

One person pays the electricity, another forgets the groceries, and nobody can see the running total.

Fake flatmates and advance-payment scams

Requests for money before a visit, pressure to move off-platform, and profiles that vanish.

Under the hood

How Domus uses Gemini API keys.

Domus calls Google's Gemini API for four things: the profile summary, match notes, the scam check and agreement drafts. Here is how those calls are made.

  1. 1Key 1 · Model ATried first. The fastest model.
  2. 2Key 1 · Model BTried if A fails or its quota is used up.
  3. 3Key 2 · Model ANext key, same model order.
  4. 4Key 2 · Model BSecond model on the second key.
  5. 5Key 3 · Models A and BLast key, if the others are used up.
  6. ✓Built-in rulesIf every call fails, Domus answers with its own rules and says so on the screen.
Keys stay on the server

Your keys are stored as secrets in Cloudflare Workers. They are sent only in a request header to Google, never to the browser, never in a URL, and never shown in any response.

Limits per person

Each person can make 5 AI calls a minute and 30 a day by default. Over the limit, the built-in rules answer instead, so no one can use up the shared keys.

Pauses after errors

A key or model that returns a quota or access error is paused for 60 seconds, then tried again. Other keys keep working in the meantime.

You can see what answered

The status line shows which key and model answered. It shows the model and key number only, never the key itself.

Free-tier limits are small and can change. The waterfall and the built-in rules keep the demo working when they run out. Text sent to Gemini is redacted first, as described in the privacy policy.

FAQ

Questions people ask first.

Is it free?

The demo is free to try. There is no payment in this build, and Domus does not move rent or deposits.

Is my phone number shared with flatmates?

No. Your number is stored only as a keyed hash plus the last four digits. Other users never see it.

Are the ID checks real?

Not in this demo. The ID step is a mock and does not check any document. The app says so on the screen.

Can I trust the scam check and the agreement?

Treat both as a starting point. The scam check can miss scams and can flag honest messages. Agreement drafts are not legal advice; a lawyer should review them before anyone signs.

How do the Gemini keys work?

Domus has up to three Google Gemini keys. It tries key 1 with its first model, then its second model, then key 2, and so on. A key that hits a quota limit is paused for a minute. If every call fails, Domus uses its built-in rules and says so. The keys never leave the server. See the section above for the full order.

Where does the AI run?

Summaries, match notes, scam checks and agreement drafts use Google's Gemini API. Phone numbers, emails, UPI IDs and links are removed before text is sent.

Can I leave and take my data with me?

Yes. Download everything Domus holds about you as a file, then delete your account from the Profile screen.
